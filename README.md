# MINI_SHELL

This repository is my implementation of a small shell.  
The goal of the challenge is to re-create key parts of shell  from the ground up.

I implemented the project in the C language.
In the project the implementation of following commands have been done:
`exit`
`echo`
`cd`
`pwd`
`type`.
The program can also run outside programs such as `grep`

### 💻 Development Environment

This project was developed and tested on Windows machine, using the WSL ubuntu:

Terminal Emulator: WezTerm

Build System: CMake

Compiler: gcc

This setup allows me to run the project scripts (.sh files) in a Linux-like environment on Windows.


### Below is how to run the project locally 

`git clone https://github.com/your-username/mini_shell.git` 

`cd mini_shell`

To run the project, you can directly execute the provided script with the Git command you want to simulate:

`./shell.sh`
